Сначала разбей работу на задачи, каждая из которых закрывается одной проверкой и умещается
в одну итерацию. Запиши их в `PLAN.md` ДО первой правки. Дальше бери строго по одной сверху:
взял → сделал → зазеленил проверку → отметил `[x]` → следующая. Не тащи три задачи разом:
при откате непонятно, что чинить, а при компакте теряется половина.
Обнаружил новую работу по ходу — добавь строкой в `PLAN.md`, не делай её вне очереди.
